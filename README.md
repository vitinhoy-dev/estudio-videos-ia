# Estúdio de Vídeos IA

App que cria vídeos de produto para TikTok Shop com IA, sem aparecer: roteiro com gancho, narração com voz feminina, cenas e legendas, montado direto no navegador.

**Abrir o app:** https://vitinhoy-dev.github.io/estudio-videos-ia/

As chaves do Gemini e da Pollinations ficam salvas só no navegador de quem usa. Nunca vão para este repositório.

Para rodar no próprio PC sem internet para o app em si, baixe o repositório e dê dois cliques em `Abrir Estudio.bat`. Veja o `LEIA-ME.txt`.
